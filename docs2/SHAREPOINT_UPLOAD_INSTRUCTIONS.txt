UPLOAD TO SHAREPOINT ONLINE

1. Extract the ZIP file.
2. Open the target SharePoint site and a document library such as Site Assets.
3. Create a folder named R2R_HTML_Portal.
4. Select Upload > Folder, then select the extracted R2R_HTML_Portal folder. Modern SharePoint supports uploading folders.
5. Verify that index.html, the other HTML files, and the assets folder retain the same relative structure.

IMPORTANT DISPLAY LIMITATION
SharePoint Online uses strict browser file handling. HTML and HTM files in libraries normally download instead of opening in the browser. An Embed web part pointing directly to index.html can therefore produce a download prompt rather than render the portal.

PUBLISHING OPTIONS
A. Recommended enterprise option: host the folder on an approved static-web host (for example an internally approved Azure Static Web Apps or web application), then place its HTTPS address in the SharePoint Embed web part. The host may need to be added to the site's allowed embed domains.

B. Admin-controlled SharePoint option: ask the SharePoint administrator whether custom script / ASPX upload is permitted on the site. If approved, an administrator or designer can convert the entry pages to ASPX and validate that CSS, JavaScript and navigation render. This changes the site's security posture and should follow company policy.

C. Content-only option: use these pages as source material to rebuild native modern SharePoint pages. This gives the strongest SharePoint integration but is not a direct HTML upload.

LOCAL PREVIEW
Open index.html from the extracted folder. If corporate browser policy blocks local scripts, run it from an approved local web server. The included JavaScript is minimal and the portal remains readable without it.
