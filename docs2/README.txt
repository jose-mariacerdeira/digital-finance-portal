R2R HTML Portal
================

Open index.html locally to preview.

Contents
- 15 responsive HTML pages mapped to slides 1-15
- Shared CSS and JavaScript in assets/
- Relative links, so the folder can be moved as a unit

SharePoint Online warning
SharePoint Online normally downloads .html files instead of rendering them. Uploading this folder preserves the files but does not automatically make it a live web site. See SHAREPOINT_UPLOAD_INSTRUCTIONS.txt for supported options and admin-dependent alternatives.
